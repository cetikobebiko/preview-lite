Hiçbir dosyayı değiştirme.

Onaylanmış planı, oluşan diff’i ve test sonuçlarını incele.

Kontrol et:

- Planın bütün maddeleri gerçekten uygulanmış mı?
- Scope dışı değişiklik yapılmış mı?
- Test sonuçları gerçek komut çıktılarıyla destekleniyor mu?
- Mimari regresyon var mı?
- Hata, yarış durumu, resource leak veya Windows I/O riski var mı?
- Eksik veya yüzeysel uygulanmış madde var mı?

Sonucu şu sınıflardan biriyle ver:

- ONAY
- KOŞULLU ONAY
- DEĞİŞİKLİK GEREKLİ

Her sorunda dosya, ilgili kod bölgesi, kanıt ve gerekli düzeltmeyi belirt.
